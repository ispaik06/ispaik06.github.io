1. 무엇을 재귀적으로 들고 가는가

Filtering의 목표는 매 시각 ttt마다 p(xt∣y1:t)p(x_t \mid y_{1:t})p(xt​∣y1:t​)를 얻는 것입니다. 정의는 L3 §8에서 conditioning set으로 구분했습니다. 매번 y1y_1y1​부터 yty_tyt​까지 전부 다시 처리하면 measurement가 쌓일수록 계산이 커집니다. Bayes filter는 직전 시각의 결과 하나만 들고 가서 새 measurement 하나로 갱신합니다.

이 강의에서는 두 distribution에 이름을 붙입니다.

belt(xt)=p(xt∣y1:t),bel‾t(xt)=p(xt∣y1:t−1)\mathrm{bel}_t(x_t) = p(x_t \mid y_{1:t}), \qquad \overline{\mathrm{bel}}_t(x_t) = p(x_t \mid y_{1:t-1}) belt​(xt​)=p(xt​∣y1:t​),belt​(xt​)=p(xt​∣y1:t−1​)

belt(xt)\mathrm{bel}_t(x_t)belt​(xt​)는 "y1y_1y1​부터 yty_tyt​까지 본 뒤 현재 state xtx_txt​에 대한 belief"라고 읽습니다. Bar가 붙은 bel‾t(xt)\overline{\mathrm{bel}}_t(x_t)belt​(xt​)는 "yty_tyt​는 아직 보지 않고 yt−1y_{t-1}yt−1​까지만 본 상태에서 xtx_txt​에 대한 predicted belief"라고 읽습니다. 둘은 같은 variable xtx_txt​의 distribution이고, 차이는 conditioning set에 yty_tyt​가 들어 있는지 하나뿐입니다.

한 step은 두 단계로 나뉩니다.

belt−1→ prediction bel‾t→ update with yt belt\mathrm{bel}_{t-1} \xrightarrow{\ \text{prediction}\ } \overline{\mathrm{bel}}_t \xrightarrow{\ \text{update with } y_t\ } \mathrm{bel}_t belt−1​ prediction ​belt​ update with yt​ ​belt​

Prediction은 transition model p(xt∣xt−1)p(x_t \mid x_{t-1})p(xt​∣xt−1​)을 쓰고, update는 measurement model p(yt∣xt)p(y_t \mid x_t)p(yt​∣xt​)를 씁니다. 두 가정 아래에서는 과거 measurement y1:t−1y_{1:t-1}y1:t−1​이 다음 belief 계산에 belt−1\mathrm{bel}_{t-1}belt−1​을 통해서만 들어갑니다. 그래서 y1:t−1y_{1:t-1}y1:t−1​ 자체를 보관할 필요가 없습니다. 이것은 §2와 §4의 유도에서 직접 확인됩니다.

3. Prediction을 숫자와 그림으로

Uncertainty의 두 출처

Prediction 식은 두 가지 uncertainty를 한 번에 처리합니다.

  1. xt−1x_{t-1}xt−1​을 정확히 모릅니다. 이것은 belt−1(xt−1)\mathrm{bel}_{t-1}(x_{t-1})belt−1​(xt−1​)에 들어 있습니다.
  2. xt−1x_{t-1}xt−1​을 알아도 transition 자체가 noisy합니다. 이것은 p(xt∣xt−1)p(x_t \mid x_{t-1})p(xt​∣xt−1​)에 들어 있습니다.

xt−1=ax_{t-1} = axt−1​=a라고 확신할 수 있으면 belt−1\mathrm{bel}_{t-1}belt−1​의 mass가 전부 aaa에 있으므로 sum에 항이 하나만 남습니다. 그러면 bel‾t(xt)=p(xt∣xt−1=a)\overline{\mathrm{bel}}_t(x_t) = p(x_t \mid x_{t-1} = a)belt​(xt​)=p(xt​∣xt−1​=a)이고, 1번은 없어지고 2번만 남습니다. 반대로 transition이 deterministic이면 2번이 없습니다. 예를 들어 xt=xt−1+utx_t = x_{t-1} + u_txt​=xt−1​+ut​이면 belief는 모양 그대로 utu_tut​만큼 옮겨집니다.

7. 왜 그대로는 계산하기 어려운가

위 알고리즘은 칸이 3개일 때는 손으로도 됩니다. 어려움은 state space가 커질 때 생깁니다.

Floating base 로봇은 base의 pose와 velocity만 해도 12차원이므로 n=10n = 10n=10은 큰 값이 아닙니다.

셋째, 일반적으로 closed form이 없습니다. Dynamics나 measurement model이 nonlinear이거나 noise가 Gaussian이 아니면, prediction과 update의 결과는 보통 유한한 개수의 parameter로 적히는 distribution family에 머물지 않습니다. Continuous state에서 중요한 예외가 하나 있습니다. Dynamics와 measurement가 linear이고, noise가 Gaussian이며 시간에 걸쳐 independent하고 서로와 x0x_0x0​에도 independent하고, p(x0)p(x_0)p(x0​)도 Gaussian이면 belief가 계속 Gaussian으로 남고 이 recursion은 Kalman filter라는 closed form을 가집니다. Kalman filter는 따로 공부합니다.
