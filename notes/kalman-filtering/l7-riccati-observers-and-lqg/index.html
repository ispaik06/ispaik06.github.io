1. Kalman filter를 observer로 읽기

Deterministic Luenberger observer의 correction은 일반적으로

x^k+=x^k−+Lk(yk−Hkx^k−)\hat x_k^+=\hat x_k^-+L_k(y_k-H_k\hat x_k^-) x^k+​=x^k−​+Lk​(yk​−Hk​x^k−​)

형태입니다. Kalman filter도 같은 innovation feedback 구조를 사용하며

Lk=KkL_k=K_k Lk​=Kk​

입니다. 차이는 gain을 정하는 기준에 있습니다.

  • Luenberger observer는 desired error dynamics에 맞춰 gain을 설계합니다.
  • Kalman filter는 linear-Gaussian model 아래에서 conditional error covariance를 최소화하는 gain을 계산합니다.

Kalman gain은 일반적으로 time-varying입니다. Pk−P_k^-Pk−​가 recursion을 따라 변하므로 같은 A,H,Q,RA,H,Q,RA,H,Q,R에서도 transient 동안 gain이 달라집니다.

2. Estimation error dynamics

Prior와 posterior errors를

ek−=xk−x^k−,ek+=xk−x^k+e_k^-=x_k-\hat x_k^-,\qquad e_k^+=x_k-\hat x_k^+ ek−​=xk​−x^k−​,ek+​=xk​−x^k+​

로 둡니다. Correction equation을 대입하면

다음 prediction error는

ek+1−=Ak+1ek++wk+1e_{k+1}^-=A_{k+1}e_k^++w_{k+1} ek+1−​=Ak+1​ek+​+wk+1​

입니다. 따라서 observer gain은 measurement가 prior error를 얼마나 제거하는지 정하고, process noise와 measurement noise가 매 step 새로운 error를 주입합니다.

3. Covariance Riccati recursion

Kalman covariance update 두 식은

Pk+=Pk−−Pk−Hk⊤(HkPk−Hk⊤+Rk)−1HkPk−,P_k^+=P_k^-- P_k^-H_k^{\top} (H_kP_k^-H_k^{\top}+R_k)^{-1} H_kP_k^-, Pk+​=Pk−​−Pk−​Hk⊤​(Hk​Pk−​Hk⊤​+Rk​)−1Hk​Pk−​,
Pk+1−=Ak+1Pk+Ak+1⊤+Qk+1P_{k+1}^-=A_{k+1}P_k^+A_{k+1}^{\top}+Q_{k+1} Pk+1−​=Ak+1​Pk+​Ak+1⊤​+Qk+1​

입니다. 첫 식을 둘째 식에 대입하면 prior covariance에 대한 Riccati map을 얻습니다.

Pk+1−=Ak+1Pk−Ak+1⊤+Qk+1−Ak+1Pk−Hk⊤(HkPk−Hk⊤+Rk)−1HkPk−Ak+1⊤(substitution).\begin{aligned} P_{k+1}^- &=A_{k+1}P_k^-A_{k+1}^{\top}+Q_{k+1}\\ &\quad- A_{k+1}P_k^-H_k^{\top} (H_kP_k^-H_k^{\top}+R_k)^{-1} H_kP_k^-A_{k+1}^{\top} &&\text{(substitution)}. \end{aligned} Pk+1−​​=Ak+1​Pk−​Ak+1⊤​+Qk+1​−Ak+1​Pk−​Hk⊤​(Hk​Pk−​Hk⊤​+Rk​)−1Hk​Pk−​Ak+1⊤​​​(substitution).​

이 nonlinear matrix recursion이 estimation Riccati recursion입니다. PPP는 value function coefficient가 아니라 conditional estimation error covariance입니다.

4. Observability와 detectability

Observability는 noise가 없는 model에서 finite output sequence와 known inputs로 initial state를 유일하게 복원할 수 있는지 묻습니다. Detectability는 unobservable modes가 존재해도 모두 stable이면 허용합니다.

Kalman filter에서 unstable unobservable mode가 있으면 sensor data가 그 mode의 error를 교정할 수 없고, dynamics가 error를 증폭합니다. 따라서 steady-state covariance가 bounded하게 수렴하기 위한 표준 조건에는 (A,H)(A,H)(A,H)의 detectability가 들어갑니다.

Time-invariant discrete model에서 자주 사용하는 충분조건은 다음과 같습니다.

  • R≻0R\succ0R≻0, Q⪰0Q\succeq0Q⪰0
  • (A,H)(A,H)(A,H)가 detectable
  • (A,Q1/2)(A,Q^{1/2})(A,Q1/2)가 stabilizable

정확한 theorem statement는 initialization과 singular covariance conventions에 따라 달라질 수 있습니다. 여기서는 이 조건들이 각각 hidden unstable modes와 process-driven modes를 제어한다는 의미를 가져갑니다. Rank와 PBH 정의는 Controllability, Observability, Stabilizability, Detectability에 있습니다.

5. Steady-state Kalman gain

Time-invariant A,H,Q,RA,H,Q,RA,H,Q,R에서 prior covariance가 Pk−→P−P_k^-\to P^-Pk−​→P−로 수렴하면 gain도 constant matrix로 수렴합니다.

K=P−H⊤(HP−H⊤+R)−1.K=P^-H^{\top}(HP^-H^{\top}+R)^{-1}. K=P−H⊤(HP−H⊤+R)−1.

Steady prior covariance는

P−=AP−A⊤+Q−AP−H⊤(HP−H⊤+R)−1HP−A⊤\boxed{ P^-= AP^-A^{\top}+Q -AP^-H^{\top} (HP^-H^{\top}+R)^{-1} HP^-A^{\top} } P−=AP−A⊤+Q−AP−H⊤(HP−H⊤+R)−1HP−A⊤​

를 만족합니다. 이는 prior-covariance convention으로 쓴 estimator DARE입니다.

Steady-state filter는 매 step covariance recursion을 반복하지 않고 fixed gain을 사용할 수 있습니다. 다만 model이 time-varying하거나 sensor availability가 바뀌거나 initialization transient가 중요한 경우에는 fixed gain이 같은 posterior를 주지 않습니다.

7. Separation principle

다음 partially observed linear system을 생각합니다.

xk=Axk−1+Buk+wk,x_k=Ax_{k-1}+Bu_k+w_k, xk​=Axk−1​+Buk​+wk​,
yk=Hxk+vk.y_k=Hx_k+v_k. yk​=Hxk​+vk​.

Full-state LQR gain을 LLL이라 하고 Kalman estimate를 사용해

uk=−Lx^k+u_k=-L\hat x_k^+ uk​=−Lx^k+​

를 적용합니다. Standard linear-Gaussian, risk-neutral assumptions 아래에서 다음 두 gain을 분리해 설계할 수 있습니다.

  1. (A,B,Qc,Rc)(A,B,Q_c,R_c)(A,B,Qc​,Rc​)로 LQR gain LLL을 설계합니다.
  2. (A,H,Q,R)(A,H,Q,R)(A,H,Q,R)로 Kalman gain KKK를 설계합니다.

Augmented closed-loop eigenstructure는 controller block과 estimator-error block으로 분리됩니다. 따라서 A−BLA-BLA−BL과 해당 estimator error dynamics가 각각 stable일 때 combined loop도 stable입니다. Stabilizing gains의 존재에는 control 쪽 stabilizability·cost detectability와 estimation 쪽 detectability·covariance DARE 조건이 각각 필요합니다. 이 조건 아래에서 controller gain은 estimation noise covariances와 독립적으로, estimator gain은 control cost weights와 독립적으로 설계할 수 있습니다.

분리 설계가 model uncertainty, nonlinearities, risk-sensitive objectives, constraints까지 자동으로 해결한다는 뜻은 아닙니다.

8. LQG

Linear-Quadratic-Gaussian control은 다음 세 요소를 결합합니다.

  • linear dynamics와 measurement model
  • quadratic expected cost
  • Gaussian process와 measurement noise

표준 LQG controller는 Kalman estimate에 LQR feedback을 적용하는 certainty-equivalent form입니다.

uk=−Lx^k+.u_k=-L\hat x_k^+. uk​=−Lx^k+​.

Finite horizon에서 additive, zero-mean, control-independent process noise와 full-state observation 아래 risk-neutral expected quadratic cost를 사용하면 process noise는 value function에 state-independent term을 추가하지만 full-state LQR gain은 바꾸지 않습니다. Persistent noise가 있는 undiscounted infinite-horizon total cost는 일반적으로 발산하므로 discounted 또는 average-cost formulation을 따로 지정해야 합니다. Partial observation에서는 Kalman filter가 conditional mean을 제공하고 separation principle이 같은 control gain을 사용할 근거를 줍니다.

LQG는 constraint를 직접 처리하지 않습니다. Input saturation이나 state constraint가 중요하면 constrained estimation과 MPC를 포함한 별도 설계가 필요합니다.

9. Nonlinear filtering으로 가는 경계

Dynamics 또는 measurement가 nonlinear이면

xk=f(xk−1,uk)+wk,yk=h(xk)+vkx_k=f(x_{k-1},u_k)+w_k,\qquad y_k=h(x_k)+v_k xk​=f(xk−1​,uk​)+wk​,yk​=h(xk​)+vk​

가 됩니다. Gaussian prior를 nonlinear map에 통과시킨 결과는 일반적으로 Gaussian이 아닙니다.

  • EKF: Jacobian으로 local linearization한 뒤 Kalman equations를 적용합니다.
  • UKF: sigma points로 mean과 covariance transformation을 근사합니다.
  • Particle filter: samples로 non-Gaussian posterior를 근사합니다.

이 방법들은 linear Kalman filter와 같은 exactness를 갖지 않습니다. 선택 기준은 nonlinearity, posterior shape, state dimension, compute budget입니다. Particle filter의 기초는 Particle Filter와 L7 · Resampling and SIR에 있습니다.
