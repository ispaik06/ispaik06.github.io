1. Index와 timing convention

이 시리즈의 model은

xk=Akxk−1+Bkuk+wk,x_k=A_kx_{k-1}+B_ku_k+w_k, xk​=Ak​xk−1​+Bk​uk​+wk​,
yk=Hkxk+vky_k=H_kx_k+v_k yk​=Hk​xk​+vk​

입니다. 따라서 한 cycle의 순서는 다음과 같습니다.

  1. 시각 k−1k-1k−1의 posterior (x^k−1+,Pk−1+)(\hat x_{k-1}^+,P_{k-1}^+)(x^k−1+​,Pk−1+​)에서 시작합니다.
  2. uku_kuk​와 process model로 시각 kkk의 prior (x^k−,Pk−)(\hat x_k^-,P_k^-)(x^k−​,Pk−​)를 계산합니다.
  3. Measurement yky_kyk​가 도착하면 innovation과 gain을 계산합니다.
  4. 시각 kkk의 posterior (x^k+,Pk+)(\hat x_k^+,P_k^+)(x^k+​,Pk+​)로 correction합니다.

일부 교재는 uk−1u_{k-1}uk−1​가 xk−1x_{k-1}xk−1​에서 xkx_kxk​로 작용한다고 씁니다. 어느 convention도 가능하지만 model equation과 code index가 일치해야 합니다.

Each cycle propagates the previous posterior into a prior and then conditions that prior on the current measurement.

2. Initialization

초기값은

x^0+=E[x0],P0+=Cov⁡(x0)\hat x_0^+=\mathbb E[x_0],\qquad P_0^+=\operatorname{Cov}(x_0) x^0+​=E[x0​],P0+​=Cov(x0​)

입니다. Initial mean을 잘 모르면 물리적으로 가능한 중심값을 두고, 그 무지를 P0+P_0^+P0+​에 반영해야 합니다.

P0+=0P_0^+=0P0+​=0은 초기 state를 exact하게 안다는 강한 주장입니다. 실제로 uncertainty가 있는데 000으로 두면 초기 measurements를 거의 무시할 수 있습니다. 반대로 지나치게 큰 P0+P_0^+P0+​는 초기 gain과 transient를 크게 만듭니다.

3. Prediction step

Prediction은

x^k−=Akx^k−1++Bkuk\boxed{ \hat x_k^-=A_k\hat x_{k-1}^++B_ku_k } x^k−​=Ak​x^k−1+​+Bk​uk​​
Pk−=AkPk−1+Ak⊤+Qk\boxed{ P_k^-=A_kP_{k-1}^+A_k^{\top}+Q_k } Pk−​=Ak​Pk−1+​Ak⊤​+Qk​​

입니다. 첫 식은 mean propagation이고, 둘째 식은 covariance propagation입니다. 유도는 L2 §2와 L2 §4에 있습니다.

4. Correction step

Measurement가 도착하면 순서대로 계산합니다.

rk=yk−Hkx^k−,r_k=y_k-H_k\hat x_k^-, rk​=yk​−Hk​x^k−​,
Sk=HkPk−Hk⊤+Rk,S_k=H_kP_k^-H_k^{\top}+R_k, Sk​=Hk​Pk−​Hk⊤​+Rk​,
Kk=Pk−Hk⊤Sk−1,K_k=P_k^-H_k^{\top}S_k^{-1}, Kk​=Pk−​Hk⊤​Sk−1​,
x^k+=x^k−+Kkrk\boxed{ \hat x_k^+=\hat x_k^-+K_kr_k } x^k+​=x^k−​+Kk​rk​​
Pk+=(I−KkHk)Pk−\boxed{ P_k^+=(I-K_kH_k)P_k^- } Pk+​=(I−Kk​Hk​)Pk−​​

또는 numerical robustness가 중요하면 Joseph form을 사용합니다.

Pk+=(I−KkHk)Pk−(I−KkHk)⊤+KkRkKk⊤.P_k^+= (I-K_kH_k)P_k^-(I-K_kH_k)^{\top} +K_kR_kK_k^{\top}. Pk+​=(I−Kk​Hk​)Pk−​(I−Kk​Hk​)⊤+Kk​Rk​Kk⊤​.

5. 전체 pseudocode

given x_post, P_post
for each time k:
    x_pred = A x_post + B u
    P_pred = A P_post A^T + Q

    if measurement exists:
        residual = y - H x_pred
        S = H P_pred H^T + R
        K = solve(S, H P_pred)^T
        x_post = x_pred + K residual
        M = I - K H
        P_post = M P_pred M^T + K R K^T
    else:
        x_post = x_pred
        P_post = P_pred

solve(S, H P_pred)^T는 SX=HP−S X=HP^-SX=HP−를 풀고 transpose해 KKK를 얻는다는 뜻입니다.

7. Inverse 대신 linear solve

수식은 Sk−1S_k^{-1}Sk−1​로 쓰지만 code에서 explicit inverse를 만들 필요는 없습니다. 원하는 식은

KkSk=Pk−Hk⊤K_kS_k=P_k^-H_k^{\top} Kk​Sk​=Pk−​Hk⊤​

이므로 transpose하면

SkKk⊤=HkPk−.S_kK_k^{\top}=H_kP_k^-. Sk​Kk⊤​=Hk​Pk−​.

SkS_kSk​가 symmetric PD이면 Cholesky-based solve를 사용할 수 있습니다. 이는 inverse를 먼저 계산해 곱하는 것보다 빠르고 numerical error가 작습니다.

inv(S)가 수학적으로 틀린 것은 아니지만, linear system을 푸는 문제를 불필요하게 explicit inverse 계산으로 바꾸는 구현입니다.

8. Symmetry와 PSD 보존

Covariance는 symmetric PSD여야 합니다. Exact arithmetic에서 Kalman equations는 이 성질을 보존하지만 finite precision에서는 작은 asymmetry나 negative eigenvalue가 생길 수 있습니다.

실전 순서는 다음과 같습니다.

  1. Correction에 Joseph form을 사용합니다.
  2. Gain은 linear solve로 계산합니다.
  3. Roundoff 수준의 asymmetry만 P←12(P+P⊤)P\leftarrow\frac12(P+P^{\top})P←21​(P+P⊤)로 정리합니다.
  4. 큰 negative eigenvalue가 생기면 clipping보다 model·index·matrix multiplication 오류를 먼저 찾습니다.

Symmetrization은 잘못된 covariance model을 고치는 방법이 아닙니다. Severe conditioning에서는 square-root filter가 더 적합하지만 이 시리즈의 범위에서는 제외합니다.

9. Measurement가 없을 때

Measurement가 누락되면 correction을 건너뜁니다.

x^k+=x^k−,Pk+=Pk−.\hat x_k^+=\hat x_k^-,\qquad P_k^+=P_k^-. x^k+​=x^k−​,Pk+​=Pk−​.

Filter를 멈추거나 이전 posterior를 그대로 유지하는 것이 아닙니다. Dynamics prediction은 계속 수행하며, process noise 때문에 uncertainty가 일반적으로 증가합니다.

Asynchronous sensors가 있으면 도착한 measurement마다 해당 HHH와 RRR로 correction할 수 있습니다. 다만 timestamp와 propagation interval을 정확히 처리해야 합니다.

10. Minimal NumPy implementation

다음 code는 식의 순서를 그대로 보존한 최소 implementation입니다.

import numpy as np


def predict(x, P, A, B, u, Q):
    x = A @ x + B @ u
    P = A @ P @ A.T + Q
    return x, P


def correct(x, P, y, H, R):
    r = y - H @ x
    S = H @ P @ H.T + R
    K = np.linalg.solve(S, H @ P).T
    x = x + K @ r
    I = np.eye(P.shape[0])
    M = I - K @ H
    P = M @ P @ M.T + K @ R @ K.T
    P = 0.5 * (P + P.T)
    return x, P, r, S

Production implementation에서는 dimension assertions, Cholesky failure handling, timestamp validation, innovation logging을 추가해야 합니다.
