IMU Attitude from Kalman-Filter Sensor Fusion

Kalman filter를 이용한 센서 융합으로 IMU의 자세 결정

MATLAB · Arduino · MPU-6050·SASA Interactive Physics project, 2023

Fusing gyroscope and accelerometer data from an MPU-6050 with a Kalman filter in MATLAB to estimate orientation. Gyro drift against accelerometer noise, and what the filter does with each. A course project report from SASA, written in Korean.

2023년 SASA 인터랙티브 피직스 자율 주제 프로젝트 보고서.

1. 초록 (Abstract)

자동차나 로봇과 같은 기계장치에는 여러 가지 센서들이 있다. 다양한 센서 정보를 바탕으로 자동차의 위치와 속도를 추정하거나 로봇의 자세를 추정한다. 이때 센서 데이터에 노이즈가 섞여서 보정이 필요하다. 칼만 필터에 대해 공부하고 행렬 연산 기반인 MATLAB으로 칼만 필터를 구현해서 직접 IMU 데이터를 보정해보기 위해 이 프로젝트를 하게 되었다.

아두이노와 6축 IMU 센서 MPU-6050로 센서 데이터를 얻었다. 이 과정에서 서보모터에 센서를 부착시켜 회전시켰다. PLA-DAQ 프로그램을 사용하여 시리얼 통신으로 받는 데이터를 엑셀에 기록하였다. 자이로 데이터와 가속도계 데이터 각각으로만 오일러 각을 계산하는 MATLAB 코드를 작성하고 결과를 분석했다. 그리고 상호 보완 관계인 자이로와 가속도계를 융합하여 칼만 필터로 각도를 추정하는 코드를 작성했다. 분석 결과, 자이로는 오차가 있는 각속도를 적분해서 시간이 지날수록 오차가 쌓이지만 짧은 시간에 대해서는 각의 변화 패턴을 잘 감지했다. 반면에 가속도계는 오차가 누적되진 않지만 오차 값 자체가 너무 컸다. 두 센서를 융합하여 칼만 필터로 보정한 결과는 완벽했다. 실제 센서가 회전한 각과 매우 근접하게 추정된 것을 확인할 수 있었다.

2. 서론 (Introduction)

칼만 필터 (Kalman filter)

칼만 필터는 노이즈가 있는 데이터에서 상태변수를 추정하는 대표적인 상태 추정 알고리즘이다. 실제로 얻는 신호나 데이터에는 노이즈가 존재할 수 밖에 없기 때문에 공학 분야에서 널리 사용된다. 칼만 필터는 선형 시스템에서 최적화된 제어기법이라고 수학적으로 증명된 기법으로 매우 좋은 성능을 갖는다.

칼만 필터는 과거와 현재 값을 기준으로 재귀적 연산을 통해 최적값을 추정하는 재귀 필터이다. 아래는 칼만 필터 알고리즘을 간략하게 나타낸 것이다.

칼만 필터는 크게 예측 과정(⓵, ⓶)과 추정 과정(⓷, ⓸, ⓹)으로 나눌 수 있다. 예측 과정에서는 행렬 A, QA,\,QA,Q를 사용하여 예측값 (x^k−, Pk−)(\hat{x}_k^-,\,P_k^-)(x^k−​,Pk−​)을 구하고, 이 예측값과 측정값 zkz_kzk​을 입력으로 받아서 추정 과정이 이뤄진다. 추정 과정에서는 행렬 H, RH,\,RH,R을 사용하여 추정값과 오차공분산 (x^k, Pk)(\hat{x}_k,\,P_k)(x^k​,Pk​)를 구한다. 최종 출력값은 x^k\hat{x}_kx^k​이다.

시스템 모델

칼만 필터는 다음과 같은 선형 상태 모델을 대상으로 한다.

xk+1=Axk+wk,zk=Hxk+vkx_{k+1} = A x_k + w_k, \qquad z_k = H x_k + v_k xk+1​=Axk​+wk​,zk​=Hxk​+vk​

여기서 xkx_kxk​는 상태변수이고, zkz_kzk​는 측정값, AAA는 시스템 행렬, HHH는 출력 행렬, wkw_kwk​는 시스템 잡음, vkv_kvk​는 측정 잡음이다. 이때 모든 잡음은 백색잡음이고, 평균이 000인 정규분포를 따른다고 가정한다. QQQ는 wkw_kwk​의 공분산 행렬, RRR은 vkv_kvk​의 공분산 행렬이다. QQQ와 RRR은 정확히 잡음의 특성을 반영해서 구성해야 하지만 여러 오차가 복합적으로 작용하기 때문에 결정하는데 한계가 있다. 그래서 실험적으로 적절한 값을 찾아야 한다. 시스템 모델과 관련된 행렬 A, H, Q, RA,\,H,\,Q,\,RA,H,Q,R이 칼만 필터의 성능을 결정한다.

  • ϕ\phiϕ : zzz축을 회전축으로 하여 xxx-yyy 좌표축이 회전한 각도.
  • θ\thetaθ : 회전된 xxx축(x′x'x′축)을 회전축으로 하여 zzz-yyy 좌표축이 회전한 각도.

Roll, Pitch, Yaw

배나 비행기, 우주선의 움직임을 설명할 때 보통 이 각들을 Roll, Pitch, Yaw 각이라고 한다. Roll, Pitch, Yaw 각각은 기체의 x, y, zx,\,y,\,zx,y,z축을 기준으로 회전반경을 나타낸다.

오일러 각의 ZYX 표현 방법이 Roll, Pitch, Yaw 표현 방법과 같다.

Roll Pitch Yaw XYZ (γ, β, α)  ⟺  Euler ZYX (α, β, γ)\text{Roll Pitch Yaw XYZ } (\gamma,\,\beta,\,\alpha) \;\Longleftrightarrow\; \text{Euler ZYX } (\alpha,\,\beta,\,\gamma) Roll Pitch Yaw XYZ (γ,β,α)⟺Euler ZYX (α,β,γ)

여기서부터는 Roll, Pitch, Yaw의 표현 방식을 따르고 Roll, Pitch, Yaw 각을 각각 ϕ, θ, ψ\phi,\,\theta,\,\psiϕ,θ,ψ으로 표기한다.

쿼터니언 (Quaternion)

쿼터니언(사원수)는 수학에서 나오는 허수 i=−1i=\sqrt{-1}i=−1​와 복소평면의 개념을 3차원으로 확장시키는 과정에서 만들어진 것이다. 허수 축 j, kj,\,kj,k를 추가하면 3차원 회전을 쉽게 표현할 수 있게 된다. 실수 성분 하나에 허수 성분 3개로 표현하는 것인데 허수 성분 3개는 3차원 좌표로 생각하고, 실수 성분을 회전 각도를 표현하는 의미로 둔다.

공학에서 쿼터니언은 회전을 나타내기 위한 표현법 중 하나이다. 오일러 각이 가장 대표적인 방법이지만 표현 방법이 어렵다. 하나의 축에 대해 어떤 각도로 회전하기만 하면 Roll, Pitch, Yaw와 같은 결과가 나오는 쉬운 방법이 쿼터니언이다.

오일러 각을 쿼터니언으로 변환시켜주는 MATLAB 내장함수 eul2quat를 사용해서 구할 수도 있다. 쿼터니언을 오일러 각으로 변환시켜주는 함수는 quat2eul이다.

자이로-가속도계 센서 MPU-6050

MPU-6050은 Accelerometer(가속도계)와 Gyroscope(자이로)가 모두 내장된 6DOF MEMS 센서로 I2C 통신 프로토콜을 통해서 데이터를 가져올 수 있다. 본 프로젝트에서는 자이로, 가속도계 센서 하나씩만 사용해서 자세 기울기를 추정하면 어떤 문제가 있고, 두 센서를 융합해서 쓰면 어떤 효과가 나타나는지 확인해보았다.

3. 방법 (Methods)

본 프로젝트에서는 Roll, Pitch, Yaw (오일러 각 ZYX) 표현법을 따랐다.

① MPU-6050 Raw Data 얻기

MPU-6050의 가속도계를 통해 x, y, zx,\,y,\,zx,y,z축 중력 가속도 데이터를 얻을 수 있고, 자이로를 통해 각속도를 알 수 있다. 시리얼 통신으로 얻은 값들을 엑셀에 실시간으로 저장하기 위해서 PLA-DAQ 프로그램을 사용하였다. PLA-DAQ 프로그램을 사용하여 엑셀 파일에 데이터를 저장하도록 아두이노 코드를 작성했다. PLA-DAQ를 이용해 얻은 데이터 기록 간격은 0.038초였고, 총 15079개의 데이터를 얻었다. (아두이노 코드에서 데이터를 0.01초 간격으로 받았지만 엑셀로 데이터를 연동받는 매크로에서 0.01초보다 느리게 입력받았다. 그래서 직접 계산했는데 데이터를 입력받은 시간을 측정해서 측정 시간을 데이터 수로 나눈 값이 약 0.038초였다.)

센서를 최대한 같은 진폭과 주기로 회전시키기 위해 서보모터에 센서를 부착했다. 아두이노 코드로는 서보모터를 −30°-30°−30° ~ 30°30°30°(센서 기준)로 좌우로 회전시키는 코드를 업로드했지만 실제로는 −25°-25°−25° ~ 35°35°35° 정도로 센서가 회전했다. 센서 기준 yyy축 중심으로 회전시켜서 Pitch 각을 변화시켰다.

4. 결과 (Results)

① 자이로 센서를 이용한 자세 추정

[그림 7]은 자이로 센서로 측정한 각속도 (p, q, r)(p,\,q,\,r)(p,q,r)로 구한 오일러 각의 변화율 (ϕ˙, θ˙)(\dot{\phi},\,\dot{\theta})(ϕ˙​,θ˙)이다. 센서를 yyy축 기준으로 회전시켰기 때문에 Roll 각 변화율이 Pitch각 변화율에 비해 매우 작은 것을 볼 수 있다. 완벽히 yyy축으로만 회전시키지 못했기 때문에 Roll각 변화율이 항상 000은 아니었다.

이를 시간에 대해 적분하여 ϕ, θ\phi,\,\thetaϕ,θ를 구하는데 우리가 주목하고 있는 θ\thetaθ의 변화만 살펴보았다. 초반에 진동하면서 전체적으로 값이 증가한다. 이는 측정 오차가 시간이 지날수록 누적되어서 측정 오차가 상당히 커지기 때문이다. 그런데 값이 증가하기만 하진 않고, 결국 180°180°180°를 넘어가게 되는 문제가 있다. 이것은 raw data를 매크로를 통해 엑셀로 가져오는 과정에서 잘못된 값이 저장되었거나 300초 이전에 있던 튀는 값으로 인해 급격하게 상승해버린 것이다. 그럼에도 불구하고 뒤쪽에서도 경향만 보면 변화 패턴은 잘 감지하고 있고, 전체적으로 값이 커져가는 것을 확인할 수 있다.

② 가속도 센서를 이용한 자세 추정

[그림 9]는 가속도계로 측정한 가속도 값이다. 여기서 AxA_xAx​가 AyA_yAy​보다 크다. 이것은 yyy축 기준 회전 운동을 했기 때문에 xxx축 방향으로 수평면이 올라가거나 내려가게 돼서 중력가속도와 원심력 성분 등이 xxx축(Roll 축) 가속도계에 측정되었기 때문이다. 따라서 실제 회전운동에 타당한 결과이다.

가속도 값을 이용해 Roll각과 Pitch각을 구하는 식은 두 가지 방법이 있었는데, 여기서는 아래의 식을 이용하였다.

ϕ=sin⁡−1 ⁣(−Aygcos⁡θ),θ=sin⁡−1 ⁣(Axg)\phi = \sin^{-1}\!\left(\frac{-A_y}{g\cos\theta}\right), \qquad \theta = \sin^{-1}\!\left(\frac{A_x}{g}\right) ϕ=sin−1(gcosθ−Ay​​),θ=sin−1(gAx​​)

[그림 11]을 보면 실제 상황과 동일하게 −25°-25°−25° ~ 35°35°35°의 범위 내에서 그래프가 진동한다. 자이로의 누적 오차와 심하게 튀는 값에 의한 오차가 모두 사라졌다. 그리고 가속도계 데이터로만 계산했을 때보다 오차가 훨씬 적다. 칼만 필터의 성능이 매우 좋음을 확인할 수 있었다. 빨간 선 그래프는 [그림 10]의 그래프이다. 실제 테스트 해봤을 때의 상황에 매우 근접한 결과를 확인할 수 있었다.

5. 결론 (Conclusion)

자이로와 가속도계의 특징을 분석한 결과를 정리하면, 두 센서가 상호 보완 관계인 것을 알 수 있다. 기울기를 자이로로 구하면 자세 변화를 잘 감지하지만 시간이 지남에 따라 오차가 누적되어 문제였다. 반면 가속도계로 구하면 시간에 따라 오차가 커지지 않고 일정 범위로 제한되는 장점이 있었다. 즉 짧게는 자이로로 결정한 자세가 좋지만, 길게 보면 가속도계로 결정한 자세가 낫다. 그래서 자이로의 누적 오차 문제를 가속도계로 보정하기 위해 센서 융합을 하는 것이고 이 과정에서 칼만 필터를 썼다. 가속도계로 계산한 쿼터니언이 칼만 필터의 측정값이고, 칼만 필터는 이 값을 자이로 각속도를 적분하여 계산한 자세와 비교하여 오차를 보정했다.

칼만 필터를 이용한 센서 융합 결과 Pitch각의 보정이 매우 잘 이루어졌다. 결과는 실제 상황과 매우 근접하게 나왔다. 칼만 필터가 측정 노이즈와 오차가 심한 데이터를 처리해서 원하는 정보인 실제 각도에 대한 신호만 골라낸 것이다. 기본적으로 행렬 연산을 하는 MATLAB을 이용하여 칼만 필터 구현을 간단하게 할 수 있었고, 자이로-가속도 센서의 자세 결정을 위한 칼만 필터의 놀라운 성능을 확인할 수 있었다.

GyroToEuler.m

function [phi, theta, psi] = GyroToEuler(p, q, r, dt)
% 자이로 각속도로 계산한 phi, theta를 반환하는 함수
%
persistent prevPhi prevTheta prevPsi
if isempty(prevPhi)
  prevPhi   = 0;
  prevTheta = 0;
  prevPsi   = 0;
end
sinPhi   = sin(prevPhi);    cosPhi   = cos(prevPhi);
cosTheta = cos(prevTheta);  tanTheta = tan(prevTheta);
phi   = prevPhi   + dt*( p + q*sinPhi*tanTheta + r*cosPhi*tanTheta );
theta = prevTheta + dt*(     q*cosPhi          - r*sinPhi );
psi   = prevPsi   + dt*(     q*sinPhi/cosTheta + r*cosPhi/cosTheta );
prevPhi   = phi;
prevTheta = theta;
prevPsi   = psi;

function [phi, theta] = AccelToEuler(Ax, Ay, Az)
% 가속도 센서로 측정한 가속도 값으로
% 롤각, 피치각을 반환하는 함수
% 결과가 더 정확하게 나오는 식
% phi = atan(Ay/Az);
% theta = atan(Ax/sqrt(Ay^2 + Az^2));
g = 9.81;
theta = asin(Ax/g);
phi = asin(-Ay/(g*cos(theta)));

KalmanToEuler.m

function [phi, theta, psi] = KalmanToEuler(A, z)
% 칼만 필터를 적용하여 쿼터니언 추정값을 구하고
% 오일러 각으로 바꿔서 반환하는 함수
persistent H Q R
persistent x P firstRun
if isempty(firstRun)
    H = eye(4);
%     Q = [ 0.5850^2      0       0       0;
%           0        0.3988^2     0       0;
%           0             0    0.4982^2   0;
%           0             0       0     0.3703^2 ];
%
%     R = [ 0.0189^2      0       0       0;
%           0        0.1665^2     0       0;
%           0             0    0.0052^2   0;
%           0             0       0     0.0012^2 ];
    Q = 2.7*eye(4);
    R = 40*eye(4);
    x = [1 0 0 0]';
    P = 1*eye(4);
    firstRun = 1;
end
xp = A*x;
Pp = A*P*A' + Q;
K = Pp*H'/(H*Pp*H' + R);
x = xp + K*(z - H*xp);
P = Pp - K*H*Pp;
e = quat2eul(x', 'XYZ');
phi = e(1);
theta = e(2);
psi = e(3);

EulerToQuaternion.m

function z = EulerToQuaternion(phi, theta, psi)
% 오일러 각을 쿼터니언으로 바꿔주는 함수
%
sinPhi = sin(phi/2); cosPhi = cos(phi/2);
sinTheta = sin(theta/2); cosTheta = cos(theta/2);
sinPsi = sin(psi/2); cosPsi = cos(psi/2);
z = [ cosPhi*cosTheta*cosPsi + sinPhi*sinTheta*sinPsi;
      sinPhi*cosTheta*cosPsi - cosPhi*sinTheta*sinPsi;
      cosPhi*sinTheta*cosPsi + sinPhi*cosTheta*sinPsi;
      cosPhi*cosTheta*sinPsi - sinPhi*sinTheta*cosPsi
    ];
